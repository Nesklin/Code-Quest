# Code Quest: Твой персональный наставник 🚀

Это веб-приложение для управления обучением, финансами и геймификации твоего пути в IT.

## 📂 Структура проекта
- `index.html` — Главная страница.
- `css/style.css` — Стили (темная/светлая тема).
- `js/` — Логика приложения (таймер, игры, финансы, план).
- `data/` — JSON-файлы с планом обучения и ресурсами.

## 🚀 Как запустить

### Вариант 1: Локально (на компьютере)
1. Скачай все файлы и сохрани их в одной папке, соблюдая структуру.
2. Открой файл `index.html` в любом браузере (Chrome, Firefox, Safari).
   *Примечание: Для корректной загрузки JSON-файлов из папки `data` лучше использовать локальный сервер (см. Вариант 2), так как браузеры блокируют fetch-запросы к файловой системе.*

### Вариант 2: Локальный сервер (Рекомендуется)
Если у тебя установлен **VS Code**:
1. Установи расширение **Live Server**.
2. Нажми правой кнопкой мыши на `index.html` → **"Open with Live Server"**.

Если у тебя установлен **Python**:
1. Открой терминал в папке с проектом.
2. Введи команду: `python -m http.server`
3. Перейди в браузере по адресу: `http://localhost:8000`

### Вариант 3: Хостинг (GitHub Pages / Netlify)
1. Загрузи все файлы в репозиторий на GitHub.
2. В настройках репозитория включи **GitHub Pages** (Source: main branch).
3. Твое приложение будет доступно по ссылке вида `https://твой-ник.github.io/code-quest/`.

## 🎮 Как пользоваться
1. **Главная:** Добавляй задачи на день. Нажми «Начать», чтобы запустить таймер (50 мин работы / 10 мин отдыха). После завершения получи XP.
2. **План:** Выбирай месяц и смотри ежедневные задания.
3. **Игра:** Следи за своим уровнем, стриком и открывай бейджи.
4. **Финансы:** Записывай расходы, чтобы видеть, куда уходят деньги и как сэкономить.
5. **Ресурсы:** Быстрый доступ к курсам и книгам.

## 💾 Сохранение данных
Все твои задачи, XP и расходы сохраняются в браузере (localStorage). Если очистишь кэш, данные пропадут.
